# ConvertX Test File Pack

The test formats/content were selected from online sample-file repositories researched for this pack:

- Codepicker sample files: https://codepicker.in/samples/
- ToolXkit sample files: https://toolxkit.com/samples/
- FileExamples test-file bundle: https://www.fileexamples.com/download-test-files

These sites advertise valid fixtures for PDF, DOCX, XLSX, CSV, JSON, XML, TXT/Markdown, images, archives and media. The current execution environment could not directly fetch arbitrary web binary downloads, so the included files are valid local fixtures based on those online sample specifications/content patterns rather than byte-for-byte copies. This keeps the pack self-contained and safe to use offline.
